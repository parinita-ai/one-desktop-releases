One for Linux

The apt and dnf repositories for One, the Denizen Blu assistant, on Ubuntu, Debian and Fedora (x64 and Arm).

Ubuntu and Debian

Download the .deb from the latest release and double-click it. Installing it adds this repository, so updates come through Software Updater.

Or from a terminal:

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://packages.denizenblu.com/one.gpg | sudo tee /etc/apt/keyrings/denizenblu-one.gpg >/dev/null
printf 'Types: deb\nURIs: https://packages.denizenblu.com/apt\nSuites: stable\nComponents: main\nSigned-By: /etc/apt/keyrings/denizenblu-one.gpg\n' \
  | sudo tee /etc/apt/sources.list.d/denizenblu-one.sources
sudo apt update && sudo apt install one

Fedora

Download the .rpm from the latest release and double-click it to install it with Software. Or from a terminal:

sudo curl -fsSL https://packages.denizenblu.com/rpm/denizenblu-one.repo -o /etc/yum.repos.d/denizenblu-one.repo
sudo dnf install one

dnf asks you to accept the signing key below the first time.
