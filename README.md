# One desktop releases

Installers and update files for the **One** desktop app for macOS and Windows,
by Denizen Blu LLC.

- **Download:** see [help.denizenblu.com/one-desktop/get-the-app](https://help.denizenblu.com/one-desktop/get-the-app).
- **Updates:** the app checks this repository's releases and updates itself.
  Pre-releases are the staging channel.

This repository holds release files only. The source is private; nothing here
is meant to be edited by hand, and releases are published by CI.
